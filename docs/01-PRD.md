# 一、项目概述

## 1.1 项目定位

**AI Job Hunter** 是一款面向个人用户的 **AI 求职助手**。

**当前 V1.0 定位**：帮你管简历 / 岗位 / 沟通 / 投递，并用 AI 分析 JD、算匹配、写打招呼与回复、出周报。  
~~自动化、智能化的 BOSS 直聘求职工具（自动搜岗、自动发消息）~~（2026-11-26：延后 V2+，且须合规接入）

## 1.2 核心价值

> **让 AI 帮你准备话术与材料，你自己决定发不发、投不投。**

~~用户只需设置好简历和求职策略，系统自动在 BOSS 上搜索合适岗位…全程无需手动操作。~~（2026-11-26）

**V1 实际路径**：你从招聘 App 复制 JD / 聊天内容进来 → AI 分析与生成 → 你复制回 App 或在看板里记进度。

## 1.3 目标用户

| 用户画像 | 描述 |
|---------|------|
| 忙碌的职场人 | 没时间每天刷站，但希望材料与话术随时可用 |
| 海投求职者 | 想快速拆 JD、写打招呼，提高效率 |
| 不善表达者 | 不知道怎么打招呼、怎么回 HR |
| ~~被动求职者（全自动挂机）~~ | ~~AI 全自动维持对话~~ → V2+ 半自动再议 |

# 二、核心业务流程

## 2.1 V1 手工辅助闭环（当前）

```
┌─────────────────────────────────────────────────────────────────────┐
│                     V1：粘贴 + AI 辅助                              │
├─────────────────────────────────────────────────────────────────────┤
│  上传简历 → AI 分析/优化建议                                        │
│  粘贴 JD → 入库 → AI 分析 → 匹配度 → 打招呼话术（可复制）             │
│  手动建对话 / 粘贴 HR 消息 → AI 推荐回复                             │
│  标记已投递 → 看板推进状态 → 时间线备注                              │
│  统计 / 漏斗 / 周报；设置：模板 + 黑名单                             │
└─────────────────────────────────────────────────────────────────────┘
```

## 2.2 ~~BOSS 自动求职流程~~（愿景，非 V1）

~~自动登录 → 搜索岗位 → 采集 JD → AI 分析 → 匹配 → 打招呼 → 监控回复 → 自动投递~~（2026-11-26：见 V2 方案；默认半自动、无授权不爬）

## 2.3 招聘平台规则（产品常识）

> 许多平台（含 BOSS）常见规则：需先打招呼，HR 回复后才方便投递。V1 **不**代替你在平台上点按钮，只生成内容并帮你记账。

| 阶段 | V1 做法 |
|-----|------|
| 打招呼 | AI / 模板生成话术 → **你**复制发送 |
| 等待回复 | 你自行查看 App；可把消息粘贴进系统 |
| 聊天回复 | AI 推荐回复 → **你**确认后发送 |
| 投递简历 | 「标记已投递」+ 看板；时间线可写备注 |

# 四、核心用户场景（V1）

## 4.1 场景一：准备材料

1. 注册 / 登录  
2. 上传简历（txt/PDF/Word）  
3. （可选）填资料：手机、求职关键词、意向城市  
4. （可选）设置默认打招呼模板与黑名单  

**系统**：解析文本；模板/黑名单入库。~~初始化 BOSS 连接~~（不做）

## 4.2 场景二：粘贴 JD 并打招呼

1. 用户粘贴 JD 创建岗位  
2. AI 分析 / 匹配度  
3. 生成打招呼（模板优先或 AI）  
4. **用户复制**到招聘 App 发送  

## 4.3 场景三：粘贴聊天并要回复

1. 手动创建对话  
2. 粘贴 HR / 自己的消息  
3. AI 推荐回复（可含意图提示）  
4. **用户复制**发送  

~~系统自动捕获 BOSS 消息~~（V2+）

## 4.4 场景四：记投递与备注

1. 在岗位详情「标记已投递」  
2. 在看板推进状态（可顺带写备注）  
3. 随时「添加备注」写入时间线  

~~自动判断并代投~~（V2+）

## 4.5 场景五：简历分析与优化

同前：查看分析 / 优化建议。

## 4.6 场景六：统计与周报

仪表盘今日概览；统计页漏斗 / 趋势；生成周报。

# 八、产品原则

1. **粘贴兜底永久保留**：即使上了平台连接，仍可手贴 JD / 聊天  
2. **半自动默认、全自动慎用**（V2+）  
3. **话术可解释、可降级**：LLM 失败不挡主流程  
4. **密钥不进文档 / 不进对话**：真实配置仅 `.env` / Secrets  
5. **合规优先**：无官方授权不做云端代登与批量爬取  
6. ~~BOSS 平台优先深度爬取~~（2026-11-26：改为合规渠道优先）

# 九、风险与限制

## 9.1 平台风险（V2 相关）

| 风险 | 态度 |
|-----|------|
| 反爬 / 封号 | **不做未授权爬取**；半自动本机、官方 API 优先 |
| Cookie 泄露 | 不进云端明文库 |

## 9.2 V1 已知限制

| 限制 | 说明 |
|-----|------|
| 不会自动上 BOSS | 岗位与聊天靠自己粘贴 |
| 扫描件 PDF / 空 Word | 可能抽不出字 |
| 无独立 HR 意图 API | 意图随推荐回复带出 |
