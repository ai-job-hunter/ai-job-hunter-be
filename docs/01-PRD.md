# 一、项目概述

## 1.1 项目定位

**AI Job Hunter** 是一款面向个人用户的 **AI 自动求职助手**。

核心定位：**自动化、智能化的 BOSS 直聘求职工具**，帮助用户自动完成岗位搜索、打招呼、聊天回复、简历投递等求职全流程。

## 1.2 核心价值

> **让 AI 帮你找工作，而不是你去找工作。**

用户只需设置好简历和求职策略，系统自动在 BOSS 上搜索合适岗位、智能打招呼、智能回复 HR、自动投递简历，全程无需手动操作。

## 1.3 目标用户

| 用户画像 | 描述 |
|---------|------|
| 忙碌的职场人 | 没时间每天刷 BOSS，但又想保持求职状态 |
| 海投求职者 | 想扩大求职覆盖面，提高效率 |
| 被动求职者 | 不想手动沟通，AI 帮你维持所有对话 |
| 应届生 | 不知道怎么打招呼、怎么跟 HR 聊天 |

# 二、核心业务流程

## 2.1 BOSS 求职完整闭环

```
┌─────────────────────────────────────────────────────────────────────┐
│                        BOSS 自动求职流程                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐           │
│  │ 自动登录 │ -> │ 搜索岗位 │ -> │ 采集 JD │ -> │ AI 分析 │           │
│  └─────────┘    └─────────┘    └─────────┘    └─────────┘           │
│                                            │                        │
│                                            v                        │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐           │
│  │ HR 回复 │ <- │ 聊天回复 │ <- │ 打招呼  │ <- │ 匹配评估 │           │
│  └────┬────┘    └─────────┘    └─────────┘    └─────────┘           │
│       │                                                              │
│       v                                                              │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐                          │
│  │ 投递简历 │ <- │ HR 感兴趣│    │ 结果记录 │                          │
│  └─────────┘    └─────────┘    └─────────┘                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 2.2 BOSS 平台特殊规则

> **重要**：BOSS 直聘平台规则 - 必须先打招呼，HR 回复后才能投递简历。

| 阶段 | 说明 |
|-----|------|
| 打招呼 | 根据 JD 生成个性化打招呼话术，直接发送给 HR |
| 等待回复 | 系统自动监控 HR 回复 |
| 聊天回复 | HR 回复后，AI 自动生成回复话术 |
| 投递简历 | **只有 HR 回复后**才能投递简历（平台限制） |

# 三、功能范围

## 3.1 V1 必须实现

### 3.1.1 BOSS 自动化模块
| 功能 | 描述 |
|-----|------|
| BOSS 自动登录 | 自动登录 BOSS 账号，支持 Cookie 持久化 |
| 岗位搜索 | 根据关键词、城市、薪资等条件自动搜索岗位 |
| JD 采集 | 自动采集岗位详情、JD 内容、公司信息 |
| 实时监控 | 监控 HR 回复、岗位状态变化 |

### 3.1.2 简历管理模块
| 功能 | 描述 |
|-----|------|
| 简历上传 | 支持 PDF、Word、图片等多种格式 |
| 简历解析 | 提取简历中的关键信息（姓名、经历、技能等） |
| 简历分析 | 分析简历优劣、指出问题、给出优化建议 |
| 简历重写 | AI 根据分析结果帮你重写简历内容 |
| 多版本管理 | 针对不同岗位类型保存多个简历版本 |

### 3.1.3 AI 分析模块
| 功能 | 描述 |
|-----|------|
| JD 解析 | 解析岗位关键词、核心技能、任职要求 |
| 匹配度分析 | 分析简历与岗位的匹配程度 |
| 简历优化建议 | 针对特定岗位给出简历优化建议 |

### 3.1.4 智能沟通模块
| 功能 | 描述 |
|-----|------|
| 打招呼话术生成 | 根据不同 JD 生成不同的打招呼话术 |
| 聊天回复生成 | HR 回复后，自动生成回复话术 |
| 对话管理 | 统一管理所有与 HR 的对话记录 |

### 3.1.5 自动投递模块
| 功能 | 描述 |
|-----|------|
| 智能选简历 | 根据岗位自动选择最匹配的简历版本 |
| 简历投递 | 自动完成简历投递操作 |
| 投递记录 | 记录所有投递历史、投递状态 |

### 3.1.6 自动化模式
| 模式 | 描述 |
|-----|------|
| 全自动 | 打招呼、聊天、投递全部自动完成 |
| 半自动 | AI 生成内容，用户确认后执行 |
| 手动模式 | 仅辅助生成内容，用户自行操作 |

### 3.1.7 求职记录模块
| 功能 | 描述 |
|-----|------|
| 投递看板 | 展示所有投递状态（待沟通、已打招呼、已投递、面试中、Offer 等） |
| 数据统计 | 投递数量、回复率、面试率等统计 |
| 周报生成 | AI 自动生成每周求职复盘报告 |

# 四、核心用户场景

## 4.1 场景一：设置求职策略

**用户操作**：
1. 上传简历（PDF/Word）
2. 设置求职关键词（如：Java 工程师、后端开发）
3. 设置求职城市、薪资期望
4. 选择自动化模式（全自动/半自动/手动）

**系统行为**：
- 解析简历内容
- 保存求职策略配置
- 初始化 BOSS 连接

## 4.2 场景二：自动打招呼

**用户操作**：
1. 系统自动发现合适岗位
2. AI 分析 JD 与简历的匹配度
3. 生成个性化打招呼话术
4. 根据自动化模式执行：
   - **全自动**：直接发送
   - **半自动**：等待用户确认
   - **手动模式**：生成话术供用户复制

**打招呼话术示例**：

```
JD 关键词：Java、Spring、微服务
生成话术：
"您好！看到您在招聘 Java 工程师，熟悉 Spring Cloud 微服务架构，
有 3 年后端开发经验。贵司的项目方向我很感兴趣，希望能进一步沟通～"
```

## 4.3 场景三：智能聊天回复

**触发条件**：HR 在 BOSS 上回复消息

**系统行为**：
1. 捕获 HR 消息内容
2. 分析 HR 意图（询问经历、谈薪资、约面试等）
3. 生成回复话术
4. 根据自动化模式执行：
   - **全自动**：直接发送
   - **半自动**：等待用户确认
   - **手动模式**：生成话术供用户复制

**回复场景示例**：

| HR 问题 | AI 回复策略 |
|--------|------------|
| "您方便说下薪资吗？" | 根据用户期望薪资回复 |
| "您有过 XX 经验吗？" | 结合简历内容回复 |
| "方便约个面试吗？" | 确认时间并表示愿意 |
| "您的期望薪资是多少？" | 提供薪资范围 |

## 4.4 场景四：自动投递简历

**前置条件**：HR 回复后，系统解锁投递功能

**系统行为**：
1. 分析 HR 消息，判断是否值得投递
2. 选择最匹配的简历版本
3. 自动完成简历投递
4. 更新投递状态

**投递决策逻辑**：
```
IF HR 回复包含以下关键词：
   - "有兴趣" / "聊聊" / "面试" / "发简历"
THEN 触发投递

AND 自动选择匹配度最高的简历版本
```

## 4.5 场景五：简历分析与优化

**用户操作**：
1. 查看简历分析报告
2. 查看 AI 给出的优化建议
3. 选择是否让 AI 重写

**分析报告内容**：
- ✅ 优势亮点
- ❌ 问题不足
- 💡 优化建议
- 📄 重写版本（可选）

## 4.6 场景六：每日求职复盘

**系统自动生成**：
- 今日打招呼数量
- 今日 HR 回复数量
- 今日投递数量
- 累计回复率、面试转化率
- 下周求职建议

# 六、自动化模式

## 6.1 模式说明

| 模式 | 打招呼 | 聊天回复 | 投递 | 适用场景 |
|-----|-------|---------|------|---------|
| 全自动 | 自动发送 | 自动回复 | 自动投递 | 信任 AI，追求效率 |
| 半自动 | 确认后发送 | 确认后回复 | 确认后投递 | 谨慎型用户 |
| 手动模式 | 生成话术 | 生成话术 | 辅助选简历 | 完全掌控 |

## 6.2 模式切换

用户可以随时在页面切换自动化模式，无需重启服务。

# 七、核心配置

## 7.1 求职策略配置

```yaml
strategy:
  keywords:
    - Java 工程师
    - 后端开发
    - Spring
  cities:
    - 北京
    - 上海
  salary:
    min: 20000
    max: 40000
  
automation:
  mode: "semi"  # full | semi | manual
  daily_greet_limit: 50    # 每日打招呼上限
  daily_apply_limit: 20   # 每日投递上限
  
response:
  auto_reply_delay: 2      # 回复延迟（秒）
  max_retries: 3           # 最大重试次数
```

## 7.2 黑名单配置

blocklist:

    - 销售
    - 保险
  job_titles:
    - 外卖骑手

# 八、产品原则

1. **BOSS 平台优先**：V1 专注 BOSS 直聘，深度适配其规则
2. **自动化可控**：用户始终可以切换自动化模式，完全掌控
3. **话术个性化**：根据不同 JD 生成不同的沟通话术，拒绝模板化
4. **数据本地化**：核心数据保存在本地，不上传云端
5. **AI 可解释**：AI 生成的每句话都有依据，用户可追溯
6. **投递合规**：遵守 BOSS 平台规则，不做违规操作

# 九、风险与限制

## 9.1 平台风险

| 风险 | 缓解措施 |
|-----|---------|
| BOSS 反爬虫 | 使用官方 App 接口，控制请求频率 |
| 账号被封 | 多账号轮换，异常检测 |
| IP 被封 | 使用代理池，自动切换 IP |

## 9.2 技术限制

| 限制 | 说明 |
|-----|------|
| 必须 HR 先回复 | BOSS 平台规则，无法绕过 |
| 文字识别准确率 | OCR 识别可能存在误差 |
| 对话理解能力 | 复杂对话可能理解不准确 |
